# 构建、安装与拼音设置

需要 Apple Silicon Mac、macOS 26 或更高版本，以及支持本项目 API 的 Swift 6 SDK。

## 构建

在项目根目录运行：

```sh
bash Scripts/build.sh
```

默认产物：

```text
~/Library/Caches/LocalPinyinLab/build/LocalPinyin.app
~/Library/Caches/LocalPinyinLab/build/PinyinSettings.app
~/Library/Caches/LocalPinyinLab/build/inputsource-tool
```

产物和 SwiftPM 缓存放在本机缓存目录，避免 Desktop/iCloud 文件提供器给签名包添加 Finder 元数据。可以用 `LOCALPINYIN_BUILD_ROOT` 指定其他非同步目录，路径必须是绝对路径；使用 `CONFIGURATION=debug` 切换构建配置。脚本先验证新包，再整体替换旧产物，失败或收到可处理的中断信号时恢复旧包。

构建只生成产物，不会替换已安装的输入法、注册或切换输入源。

## 安装与打开

- 将完整的 `LocalPinyin.app` 安装到 `~/Library/Input Methods/`。更新时备份旧包，再整体替换，不能只替换可执行文件或合并旧资源。首次安装后重新登录，在 macOS 的键盘输入源设置中添加“拼音”。
- 将完整的 `PinyinSettings.app` 安装到 `/Applications/拼音设置.app`；仅供当前用户使用时，也可放在 `~/Applications/拼音设置.app`。它是普通 App，可从访达“应用程序”打开。

输入法菜单中的 **拼音设置…** 优先打开“应用程序”里的设置 App。若没有独立安装，菜单会回退到输入法内嵌的同一设置 App。输入法的显示名称和“中英”菜单图标保持不变。

“拼音设置”的侧栏包含两个页面：

- **使用说明**：集中展示模式切换、大小写锁定、候选选择与翻页、组合编辑和朗读快捷键，保留 macOS 键盘设置入口。“目标语言朗读”卡片显示当前声音及缺声提示，并提供辅助功能设置入口。大小写锁定须先按住 `Shift`，再按 `Caps Lock`。
- **语言包**：选择翻译目标语言，查看当前系统支持情况和离线语言包状态，按需准备或重新检查。

关闭设置窗口不影响输入法继续工作，再次打开 App 可恢复窗口。输入模式和快捷键仍由输入法处理；设置 App 不会在启动时切换输入源或下载语言包。

## 选择语言与准备离线语言包

打开 **拼音设置 → 语言包**。默认目标为英语，可选英语、日语、韩语、法语、德语、西班牙语、葡萄牙语（巴西）、意大利语、俄语、阿拉伯语、印地语、泰语、越南语、印度尼西亚语和土耳其语，共 15 种常用语言。具体可用性以页面读取的系统状态为准。

**检查全部语言包** 一次刷新全部 15 种翻译方向的状态；启动设置 App、回到前台时也会刷新。状态实时从系统读取，不另行保存。每张目标语言卡片分两行展示名称和状态：“已安装”配绿色勾，“待准备”配灰色下载图标；“待准备”表示中文与目标语言尚未全部就绪。当前语言另有强调色边框和 **当前使用** 文字徽标；选择与准备状态独立。

点击目标语言即保存并立即同步到输入法，无需重启。当前拼音和候选选择保留，译文按新目标刷新，正在进行的朗读停止；下次使用已设置的朗读快捷键时，以新目标语言朗读。保存失败时页面会提示，仍保留原选择。

选择语言只检查状态，不下载。点击 **准备语言包**，直接打开 **系统设置 → 通用 → 语言与地区 → 翻译语言** 的“可供下载的语言”列表，由你自行找到目标语言并点按 **下载**；中文（普通话，简体）若尚未安装，也在该列表中下载。拼音设置不再弹出指定两种语言的下载提示，也不显示单独的中文栏目。

打开列表不会开始下载或将语言标为已安装，也不会锁住目标语言选择。返回拼音设置后会自动重新检查；若下载仍在后台进行，可稍后点击 **检查全部语言包**。只有系统确认中文与目标语言均已准备好，才显示“已安装”。打开系统设置失败时会显示手动路径，可以再次点击重试。下载可能需要网络，日常翻译只使用本地语言包；中文输入可继续使用。

在 **拼音设置 → 使用说明 → 目标语言朗读** 查看当前目标语言的本地 Apple 声音，并自定义朗读快捷键；在“语言包”切换目标后，此处同步更新。若没有对应声音，可点击 **打开辅助功能设置** 补充，打开失败也会在卡片内提示；朗读不会改用英语或其他语言。完成后可关闭设置窗口继续输入。

### 移除当前外语语言包

已安装时，“中文 → 目标语言”标题右侧显示 **删除语言包…**。点击后先显示当前外语名称及保留中文的说明，再点 **打开翻译语言** 进入 macOS 的语言包管理窗口。在系统窗口中仅移除目标外语（例如“日语”），保留中文语言包。系统模型由多个 App 共享，移除后其他 App 也不能使用该外语进行离线翻译。

macOS 没有向普通应用开放直接卸载语言包的接口，因此最终“移除”由你在系统窗口中操作；拼音设置不会自行删除任何语言包，也不会在打开窗口时把状态假改成“未安装”。回到拼音设置会重新查询实际安装状态，确认移除后原位置恢复“准备语言包”按钮。打开失败时会显示手动路径：**系统设置 → 通用 → 语言与地区 → 翻译语言**。

### 自定义朗读快捷键

在“目标语言朗读”卡片中选择 Command、Option、Control、Shift 修饰键和可选的普通按键，组成 **两个或三个键**，点击 **保存快捷键**。支持两个或三个修饰键，也支持一个或两个修饰键加一个普通按键（例如 `Shift + Tab`、`Control + Shift + R`）；不支持两个普通字母同时按下。**恢复默认** 将草稿改为 `Command + Option`，仍需点击保存。保存成功后立即同步到输入法，重启后保留；保存失败会显示提示，继续使用原快捷键。

默认 `Command + Option` 需要单独按下并全部松开后朗读；组合过程中按其他键、增加其他修饰键、点击或拖动鼠标、滚动、切换应用会取消本次触发。含普通按键的组合在普通键按下时触发，长按不重复启动。所有组合都只在中文候选框显示且当前候选已有可朗读译文时有效，输入文字和候选保持不变；其他状态保持原有按键处理。

输入法自己的模式切换、候选编辑组合不可设为朗读键。其他软件可能使用相同组合；设置页不宣称能够检查所有软件的冲突。纯修饰键额外检查会话键鼠事件计数，以减少系统先截获其他快捷键造成的误触；仍应在常用软件中验证。

也可以单独构建并打开设置 App：

```sh
bash Scripts/build-settings.sh
open "$HOME/Library/Caches/LocalPinyinLab/build/PinyinSettings.app"
```

如果设置了 `LOCALPINYIN_BUILD_ROOT`，请打开脚本最后输出的应用路径。输入法包内的设置 App 位于 `Contents/Resources/PinyinSettings.app`。原来的 `build-translation-setup.sh` 保留为兼容入口，生成同一个设置 App。

## 常用字词学习

选词并提交后，同样拼音、同样转换长度的候选按使用次数优先，同频时优先最近使用的；未学习候选保留引擎原序，常用单字不会越过较长词句的候选槽位。逐段选择在最终提交时计入，`Esc` 取消和 `Shift + ←` 撤回的选择不计入。

记录仅保存在 `~/Library/Application Support/LocalPinyinLab/candidate-usage.json`，包含选择的拼音、中文、次数和最近使用序号，不保存文档前后文，也不与系统拼音词库同步。从新版本开始积累，重启输入法或电脑后保留。文件损坏时保留原文件并重新积累；保存失败时当前进程仍可使用内存中的排序。

## 回归验证

```sh
bash Scripts/check.sh
```

- `input-checks`：标点、模式、大写锁定、分页、组合编辑、提交学习与撤回/取消，以及切换翻译语言、缓存、异步响应隔离和自定义朗读快捷键。
- `worker-checks`：在临时目录运行假 worker，覆盖取消、超时、失败重试和子进程回收，并验证个人词频排序、持久化和异常恢复；不更改个人词库或系统输入源。
- `presentation-checks`：窗口尺寸、长文本布局、候选序号与辅助功能语义。
- `PinyinSettingsTests`：准备按钮打开系统语言列表、打开失败重试、返回后的真实安装状态与取消检查后的过期结果隔离；另覆盖删除入口、快捷键草稿、保存失败、恢复默认与外部刷新；使用注入状态，不下载语言包或修改用户偏好。

这些检查不等于真实宿主验收。更新已安装的输入法后，还应在常用编辑器、浏览器和多屏环境验证候选定位、翻页、模式提示，并使用 VoiceOver 检查候选及译文。界面检查可通过 `presentation-checks --render-directory <绝对目录>` 导出离屏预览图片；导出图仅用于布局检查。

### 候选框间歇消失时的诊断

若拼音仍能按空格转为中文，但候选框不见了，先保留现场，记下出现时间、宿主软件以及是否刚切换桌面或全屏。输入法会在系统统一日志中记录候选窗口的显示请求、主动隐藏、遮挡与桌面变化，关联同一输入控制器；只记录窗口标识、几何位置、层级和可见状态，不记录拼音、候选、文稿、剪贴板或窗口标题。

```sh
/usr/bin/log show --last 10m --style compact --predicate 'subsystem == "local.pinyinlab.inputmethod" AND (category == "CandidateWindow" OR category == "InputController")'
```

`show-request` 表示输入法请求显示，`ordered` / `settled` 对比立即与延后采样的状态，`hide-request` 表示输入法主动隐藏；`intent=true` 时结合 `visible`、`activeSpace`、`onscreen` 判断系统窗口是否实际显示。稳定的重复状态不重复写入，日志保留时长由 macOS 管理。

从 35 版开始，展示后会延迟检查窗口是否仍在当前桌面。若系统清理桌面时丢失了候选窗口的桌面关联，且这次展示仍有效、前台软件未变，则自动重建候选窗口，保留当前视图、选中项、位置和层级，不清空拼音或重新查询候选。每次展示最多恢复一次；取消输入、更新候选或切换前台软件会阻止旧任务恢复。恢复时记录 `rebuild-space`，随后同一 `owner` 会出现新的窗口编号。单纯被其他窗口遮挡不会触发恢复。
