# 构建、安装与拼音设置

需要 Apple Silicon Mac、macOS 26 或更高版本，以及支持本项目 API 的 Swift 6 SDK。

## 构建

在项目根目录运行：

```sh
bash Scripts/build.sh
```

默认产物：

```text
~/Library/Caches/LocalPinyinLab/build/LocalPinyin.app
~/Library/Caches/LocalPinyinLab/build/PinyinSettings.app
~/Library/Caches/LocalPinyinLab/build/inputsource-tool
```

产物和 SwiftPM 缓存放在本机缓存目录，避免 Desktop/iCloud 文件提供器给签名包添加 Finder 元数据。可以用 `LOCALPINYIN_BUILD_ROOT` 指定其他非同步目录，路径必须是绝对路径；使用 `CONFIGURATION=debug` 切换构建配置。脚本先验证新包，再整体替换旧产物，失败或收到可处理的中断信号时恢复旧包。

构建只生成产物，不会替换已安装的输入法、注册或切换输入源。

## 安装与打开

- 将完整的 `LocalPinyin.app` 安装到 `~/Library/Input Methods/`。更新时备份旧包，再整体替换，不能只替换可执行文件或合并旧资源。首次安装后重新登录，在 macOS 的键盘输入源设置中添加“拼音”。
- 将完整的 `PinyinSettings.app` 安装到 `/Applications/拼音设置.app`；仅供当前用户使用时，也可放在 `~/Applications/拼音设置.app`。它是普通 App，可从访达“应用程序”打开。

输入法菜单中的 **拼音设置…** 优先打开“应用程序”里的设置 App。若没有独立安装，菜单会回退到输入法内嵌的同一设置 App。输入法的显示名称和“中英”菜单图标保持不变。

“拼音设置”的侧栏包含两个页面：

- **使用说明**：集中展示模式切换、大小写锁定、候选选择与翻页、组合编辑和朗读快捷键，保留 macOS 键盘设置入口。“目标语言朗读”卡片显示当前声音及缺声提示，并提供辅助功能设置入口。大小写锁定须先按住 `Shift`，再按 `Caps Lock`。
- **语言包**：选择翻译目标语言，查看当前系统支持情况和离线语言包状态，按需准备或重新检查。

关闭设置窗口不影响输入法继续工作，再次打开 App 可恢复窗口。输入模式和快捷键仍由输入法处理；设置 App 不会在启动时切换输入源或下载语言包。

## 选择语言与准备离线语言包

打开 **拼音设置 → 语言包**。默认目标为英语，可选英语、日语、韩语、法语、德语、西班牙语、葡萄牙语（巴西）、意大利语、俄语、阿拉伯语、印地语、泰语、越南语、印度尼西亚语和土耳其语，共 15 种常用语言。具体可用性以页面读取的系统状态为准。

**检查全部语言包** 一次刷新全部 15 种语言的安装状态；启动设置 App、回到前台时也会刷新，下载完成后更新当前状态并刷新列表。安装状态实时从系统读取，不另行保存。每张语言卡片分两行展示名称和安装状态：“已安装”配绿色勾，“未安装”配灰色下载图标。当前语言另有强调色边框和 **当前使用** 文字徽标；选择与安装状态独立，选中未安装的语言仍明确显示“未安装”。

点击目标语言即保存并立即同步到输入法，无需重启。当前拼音和候选选择保留，译文按新目标刷新，正在进行的朗读停止；下次按 `Control + Shift + R` 使用新目标语言朗读。保存失败时页面会提示，仍保留原选择。

选择语言只检查状态，不下载。系统支持但尚未安装时，点击 **准备语言包**，按 Apple 系统提示完成准备。准备可能需要网络，日常翻译只使用已安装的本地语言包。页面区分检查中、尚未安装、准备中、已就绪、系统不支持或失败；失败可重试，也可重新检查。准备期间中文输入仍可使用。

未点击下载就关闭系统提示（包括按 `Esc`）后，页面会结束准备状态，可重新准备或切换语言。若下载仍在后台进行，可稍后点击 **检查全部语言包**；只有系统确认安装完成才显示“已安装”。

在 **拼音设置 → 使用说明 → 目标语言朗读** 查看当前目标语言的本地 Apple 声音及 `Control + Shift + R` 朗读说明；在“语言包”切换目标后，此处同步更新。若没有对应声音，可点击 **打开辅助功能设置** 补充，打开失败也会在卡片内提示；朗读不会改用英语或其他语言。完成后可关闭设置窗口继续输入。

也可以单独构建并打开设置 App：

```sh
bash Scripts/build-settings.sh
open "$HOME/Library/Caches/LocalPinyinLab/build/PinyinSettings.app"
```

如果设置了 `LOCALPINYIN_BUILD_ROOT`，请打开脚本最后输出的应用路径。输入法包内的设置 App 位于 `Contents/Resources/PinyinSettings.app`。原来的 `build-translation-setup.sh` 保留为兼容入口，生成同一个设置 App。

## 回归验证

```sh
bash Scripts/check.sh
```

- `input-checks`：标点、模式、大写锁定、分页、组合编辑，以及切换翻译语言、缓存和异步响应隔离。
- `worker-checks`：在临时目录运行假 worker，覆盖取消、超时、失败重试和子进程回收；不更改系统输入源。
- `presentation-checks`：窗口尺寸、长文本布局、候选序号与辅助功能语义。
- `LanguagePacksModelTests`：关闭准备提示后的状态恢复、重试与迟到回调隔离，以及安装状态确认；使用注入状态，不下载语言包或修改语言偏好。

这些检查不等于真实宿主验收。更新已安装的输入法后，还应在常用编辑器、浏览器和多屏环境验证候选定位、翻页、模式提示，并使用 VoiceOver 检查候选及译文。界面检查可通过 `presentation-checks --render-directory <绝对目录>` 导出离屏预览图片；导出图仅用于布局检查。
