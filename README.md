# 拼音 LocalPinyinLab

一款 macOS 输入法，支持中文拼音输入、英文直出、候选词多语言翻译和对应语言朗读。

## 功能

- **中文拼音输入**：使用本机 Apple 拼音引擎生成词语和整句候选，支持逐段选词，选定前半段后继续转换剩余拼音。
- **常用字词优先**：自动记住已选并提交的中文，同样拼音下使用次数更多的字词排在前面，同频时优先最近使用的。逐段选词也能学习；撤销或取消的选择不计入。学习记录保存在本机，重启后保留，从启用此功能后的输入开始积累。
- **中英模式切换**：`Caps Lock` 灯灭时输入中文拼音，灯亮时输入英文。模式提示优先显示在光标上方，顶部空间不足时向侧面避让，约 1 秒后消失。英文默认小写，按住 `Shift` 输入大写；切换应用或重新启动时按实际灯状态对齐模式。
- **英文大写锁定**：**先按住 `Shift`，再按 `Caps Lock`**，进入英文并持续输入大写；再次按相同顺序操作，恢复英文小写。无论当前是中文拼音还是英文小写，都按此顺序操作；先按 `Caps Lock` 再按 `Shift` 不会触发大写锁定，而会先执行普通中英切换。两种英文状态都保持 Caps Lock 灯亮，单按 Caps Lock 灭灯切回中文并解除大写锁定。开关时沿用模式提示的位置与约 1 秒的显示时长，不打断输入；保持灯亮切换应用时保留大写锁定。
- **标点随模式切换**：拼音模式输出 `，。？！：；（）【】《》、` 等中文标点，单双引号按光标前文配对；英文模式保留英文标点。拼音中的 `'` 仍用于分隔音节，例如 `xi'an`。
- **双语候选**：在中文候选旁显示目标语言的译文，默认英语，提供 15 种常用语言选项。逐段选词时翻译当前候选片段；译文异步加载，不影响中文选词。
- **英文词性提示**：候选框在英文单词译文左侧显示 `n.`（名词）、`v.`（动词）、`adj.`（形容词）、`adv.`（副词）等缩写，译文保持对齐。词性由本机语言模型在后台推断并补充显示，仅供参考；不确定的单词、短语和整句不标注。词性不会加入译文朗读。
- **Touch Bar 双语预览**：在配备 Touch Bar 的 MacBook 上，候选框显示期间，触控栏中间同步显示当前预选中文和目标语言译文；上下选词、翻页和翻译完成时同步更新，候选关闭后恢复原来的触控栏。上下两行显示，过长内容以省略号收尾，完整内容仍可在候选框查看。此功能使用系统未公开的 Touch Bar 接口；系统不支持时自动跳过，不影响输入。
- **译文朗读**：默认单独按下 `Command + Option` 并全部松开，使用本地 Apple 声音朗读当前选中项已显示的译文，语言随翻译目标同步，保留当前输入内容。可在「拼音设置 → 使用说明 → 目标语言朗读」自定义两键或三键组合，保存后立即生效；仅在候选译文已就绪时触发。没有对应语言的本地声音时提示不可用，不回退到英语。
- **竖排候选窗口**：白色背景、蓝色选中高亮，每页最多 9 项。拼音候选与译文均保持左对齐，中文与译文区域（含词性）固定间隔 40 px；窗口由内容撑开，最大宽度为 600 px，并受屏幕可用宽度限制。所有过长候选与译文都会自动换行，不限于选中项；屏幕高度不足时保留当前选中项，并提示用上下方向键查看其他候选。单条候选或译文超过可用高度时，可用 `Shift + Page Up / Page Down` 滚动查看全文（MacBook 可用 `Fn + Shift + ↑ / ↓`），不改变当前选择。候选与选中状态提供辅助功能信息。支持空格选中、数字键 `1`–`9` 选词、上下方向键移动；`←` / `→` 切换上一页 / 下一页，也支持 `Page Up` / `Page Down`。首页和末页不循环翻页。
- **组合编辑**：`Backspace` 删除待转换拼音，`Shift + ←` 撤回已选片段，`Esc` 取消当前组合。删完剩余拼音后，可按空格提交已选中文。回车提交当前中文与剩余拼音，不额外插入换行。
- **候选过滤**：过滤含表情符号的候选，保留普通文字、数字和标点。
- **拼音设置 App**：可从“应用程序”打开，也可从输入法菜单选择“拼音设置…”。“使用说明”集中展示操作、快捷键和目标语言的朗读声音，提供 macOS 键盘及辅助功能设置入口；“语言包”可选择翻译目标，点击语言即保存并同步译文和朗读，无需重启输入法。
- **本地翻译与朗读**：日常翻译仅使用已安装的 Apple 离线语言包。“检查全部语言包”一次读取 15 种翻译方向的状态，检查期间可取消，超时后可重新检查；目标语言卡片显示“已安装”或“待准备”，当前语言另有强调色边框和“当前使用”标记。点击“准备语言包”直接打开系统完整语言列表，由用户自行选择下载；返回后自动刷新状态。已安装时，同一位置显示“删除语言包…”入口，提示在系统设置中仅移除当前外语、保留中文。缺少语言包时仍可使用中文候选。语言列表、声音状态与准备步骤见 [设置说明](Docs/SETUP.md)。
