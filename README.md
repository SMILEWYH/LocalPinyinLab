# 拼音 LocalPinyinLab

一款 macOS 双语输入法，支持中文拼音输入、英文直出、候选词英文翻译和英文朗读。

## 功能

- **中文拼音输入**：使用本机 Apple 拼音引擎生成词语和整句候选，支持逐段选词，选定前半段后继续转换剩余拼音。
- **中英模式切换**：按 `Caps Lock` 或 `Control + Shift + Space` 切换中文拼音与英文直出。英文默认小写，按住 `Shift` 输入大写；切换应用时保留当前模式。
- **英文大写锁定**：按 `Shift + Caps Lock` 进入英文并持续输入大写，再按一次恢复英文小写；切回中文时自动解除锁定。开关时在光标附近显示约 1 秒的状态提示，不打断输入；切换应用时保留锁定状态。
- **标点随模式切换**：拼音模式输出 `，。？！：；（）【】《》、` 等中文标点，单双引号按光标前文配对；英文模式保留英文标点。拼音中的 `'` 仍用于分隔音节，例如 `xi'an`。
- **双语候选**：在中文候选旁显示对应的英文译文，逐段选词时翻译当前候选片段。译文异步加载，不影响中文选词。
- **英文朗读**：按 `Control + Shift + R`，使用本地 Apple 英语声音朗读当前选中项已显示的英文译文，保留当前输入内容。
- **竖排候选窗口**：白色背景、蓝色选中高亮，每页最多 9 项。支持空格选中、数字键 `1`–`9` 选词、上下方向键移动；`←` / `→` 切换上一页 / 下一页，也支持 `Page Up` / `Page Down`。首页和末页不循环翻页。
- **组合编辑**：`Backspace` 删除待转换拼音，`Shift + ←` 撤回已选片段，`Esc` 取消当前组合。回车提交当前中文与剩余拼音，不额外插入换行。
- **候选过滤**：过滤含表情符号的候选，保留普通文字、数字和标点。
- **本地翻译与朗读**：使用已安装的 Apple 中英离线语言包和英语声音。缺少语言包时仍可使用中文候选，并显示翻译不可用提示。
