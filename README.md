# 拼音 LocalPinyinLab

一款 macOS 双语输入法，支持中文拼音输入、英文直出、候选词英文翻译和英文朗读。

## 功能

- **中文拼音输入**：使用本机 Apple 拼音引擎生成词语和整句候选，支持逐段选词，选定前半段后继续转换剩余拼音。
- **中英模式切换**：`Caps Lock` 灯灭时输入中文拼音，灯亮时输入英文；也可按 `Control + Shift + Space` 切换，并同步指示灯。模式提示优先显示在光标上方，顶部空间不足时向侧面避让，约 1 秒后消失。英文默认小写，按住 `Shift` 输入大写；切换应用或重新启动时按实际灯状态对齐模式。
- **英文大写锁定**：**先按住 `Shift`，再按 `Caps Lock`**，进入英文并持续输入大写；再次按相同顺序操作，恢复英文小写。无论当前是中文拼音还是英文小写，都按此顺序操作；先按 `Caps Lock` 再按 `Shift` 不会触发大写锁定，而会先执行普通中英切换。两种英文状态都保持 Caps Lock 灯亮，单按 Caps Lock 灭灯切回中文并解除大写锁定。开关时沿用模式提示的位置与约 1 秒的显示时长，不打断输入；保持灯亮切换应用时保留大写锁定。
- **标点随模式切换**：拼音模式输出 `，。？！：；（）【】《》、` 等中文标点，单双引号按光标前文配对；英文模式保留英文标点。拼音中的 `'` 仍用于分隔音节，例如 `xi'an`。
- **双语候选**：在中文候选旁显示对应的英文译文，逐段选词时翻译当前候选片段。译文异步加载，不影响中文选词。
- **英文朗读**：按 `Control + Shift + R`，使用本地 Apple 英语声音朗读当前选中项已显示的英文译文，保留当前输入内容。
- **竖排候选窗口**：白色背景、蓝色选中高亮，每页最多 9 项。双列宽度随屏幕约束，选中长候选和译文可换行展开；候选与选中状态提供辅助功能信息。支持空格选中、数字键 `1`–`9` 选词、上下方向键移动；`←` / `→` 切换上一页 / 下一页，也支持 `Page Up` / `Page Down`。首页和末页不循环翻页。
- **组合编辑**：`Backspace` 删除待转换拼音，`Shift + ←` 撤回已选片段，`Esc` 取消当前组合。删完剩余拼音后，可按空格提交已选中文。回车提交当前中文与剩余拼音，不额外插入换行。
- **候选过滤**：过滤含表情符号的候选，保留普通文字、数字和标点。
- **本地翻译与朗读**：使用已安装的 Apple 中英离线语言包和英语声音。缺少语言包时仍可使用中文候选；输入法菜单提供语言包准备入口，显示准备状态并支持失败重试。
